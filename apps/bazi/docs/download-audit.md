# 網站與 LINE 匯出審核（2026-10-20）

範圍：顧問 Prompt／TXT／MD／PNG、網站與 LINE 一致性、下載頁狀態、錯誤復原及一次性授權。未重寫四柱、節氣、起運或論命決策規則。

## 發現與修正

| 問題 | 調整 | 驗證 |
|---|---|---|
| 網站 PNG 在非同步繪圖後背景觸發下載，手機可能沒有儲存介面 | 網站與 LINE 共用 `file-delivery.js/css`，先顯示預覽，再由使用者明確儲存／分享／開啟 | 產生過程、無自動下載、正確檔名與原始 Blob 測試 |
| 舊手機 File 建構或分享不支援時可能連預覽也失敗 | File 只用於可選的原生分享，失敗保留其他操作 | 缺少 File、分享取消／錯誤測試 |
| 分享或複製尚未結束時切換連結，舊操作會改寫新狀態 | 每份檔案的非同步操作綁定版本，切換時清除舊文字及 Blob URL | 競態、資源釋放與頁面返回快取測試 |
| 過期連結仍顯示重試；網關錯誤可變成大段 HTML | 400／401／403／404／410 顯示重新取連結，409／5xx 可重試；不顯示代理回應 HTML | HTTP 分類及重試測試 |
| HTTP 200 的空檔、錯誤格式、殘缺內容被當成成功 | 驗證 MIME、非空、PNG 簽章及可用的傳輸長度 | 空檔、HTML、PNG、截斷串流測試 |
| 程式檔未載入時只有無反應按鈕 | 初始化前停用載入，提供重整與載入失敗訊息，資產帶版本參數 | 初始化失敗測試；靜態資產可公開存取 |
| 程序內 token 鎖無法跨兩個部署程序協調 | 繪圖成功後以本機 exclusive create 或 R2 conditional create 留存使用收據，再清除權限；到期在渲染後再次確認 | 多 consumer 實例只一次成功、R2 請求及儲存失敗測試、HTTP 重播拒絕 |

## 內容核對

- 使用者的核心義原檔已移至原工作區 `Bazi_LineBOT_md/八字命理顧問_命盤分析前必讀核心主義.md`；與發布用 `docs/advisor-core.md` 的 SHA-256 相同。十九節核心義產物檢查通過，沿用既有排除短期流運三列的規則。
- 網站與 LINE 對相同輸入及年份的 Prompt 完全相同；TXT／MD 內容一致，以核心義起首，不含流月、舊 JSON、undefined 或其他命主資料。
- 六柱圖片沿用結構化 payload；由左至右時、日、月、年、大運、流年。五色、藏干、星運、自坐、空亡、起運、大運、流年及關係提示保持共用規則。
- 不將五行季節狀態當作日主旺衰／用神定論；先原局、再加入運年分析的指示保留。舊論命規則與歷史 Prompt 函式仍存在，未回接至目前的顧問匯出。

## 回歸與驗證邊界

`npm run test:bazi:line` 包含 canonical、簽章 webhook HTTP 整合、9 組下載操作及 2 組儲存層一次性測試；另執行匯出 7 組、曆法／命主、Prompt 隔離、存取保護與 site verify。停用系統字型重跑，原生 PNG 仍可解碼且五色存在，已檢視測試命盤圖片。

新增的前端互動測試以 Node VM 與 DOM 替身執行；R2 conditional create 使用 SDK 請求替身驗證。本機儲存、HTTP 伺服器與 PNG 編碼實際執行。未發送正式 LINE 訊息、未建立正式測試帳號、未將測試檔案寫入正式 R2。本回合瀏覽器控制停用，不能把這些測試當成手機 LINE App 或新版瀏覽器視覺驗收。

## 一次性收據維護

收據位於私有 `line/download-receipts/<token>.json`，僅含使用與原授權到期時間，不含命盤或帳號。必須保留至原 token 到期後才能清除；若日後設定 R2 lifecycle，應僅針對此收據前綴，並保留至少數日，不套用到命主／artifact 前綴。這次未變更 bucket lifecycle 或權限。

R2 原子條件寫入依據：[Cloudflare S3 相容性文件](https://developers.cloudflare.com/r2/api/s3/api/)、[條件寫入擴充](https://developers.cloudflare.com/r2/api/s3/extensions/)。本機多程序需共用同一 storage 路徑；R2 部署需共用同一 bucket 與 key prefix。
