# 顧問核心義與命盤匯出

更新：2026-10-20。本功能位於論命頁 `bazi-analysis.html`，不改出生四柱、節氣或既有起運與大運計算。

## 核心義來源

- 使用者提供：`八字命理顧問_命盤分析前必讀主核心義.md`。
- `advisor-core.md` 保存原文，桌面原始檔不修改。
- `../advisor-core.js` 保存瀏覽器可直接載入的版本與來源 SHA-256。
- 僅刪除原文分析順序中的流月、流日、流時三列，符合本次原局／大運／流年範圍；其餘十九節完整保留。
- 複製、`.txt`、`.md` 共用同一份 `analysis.aiPrompt`，以核心義全文起首，再接終身顧問工作方式及此命主資料，不附舊 JSON 或舊初判。

更新原文副本後執行：

```sh
node apps/bazi/scripts/build-advisor-core.mjs
node --test apps/bazi/tests/export.test.cjs
```

## 圖檔

`../chart-export.js` 由結構化 payload 產生衍生資料，供文字與 PNG 共用；Canvas 在瀏覽器本地繪製，不依賴畫面文字、外部截圖服務或圖片模型。

- PNG 邏輯寬度 1280，輸出解析度為兩倍；高度依關係提示數量自動調整。
- 六柱由左至右為時、日、月、年、大運、流年，對應參考圖版面。
- 包含天干十神、藏干與十神、星運、自坐、空亡、十步大運、參考年份所在十年的流年、季節五行及柱位明確的關係提示。
- 五行配色為木綠、火紅、土棕、金灰、水藍。干支與藏干依其自身五行上色。
- 大運與指定流年以框線標示；歲數與年份沿用主頁現有資料，不套用範例截圖的 1980／2020 等起運數值，也不聲稱精確交運月日。
- 不輸出流月，不匯出操作按鈕、手機狀態列或 Prompt。

## 衍生規則

星運以日干對各支取十二長生；自坐以各柱自己的干對自己的支取十二長生。採陽干順、陰干逆；土與火同序。空亡以該柱六十甲子所在旬取兩支。運算對照參考 [lunar-javascript 原始碼中的長生與旬空實作](https://github.com/6tail/lunar-javascript/blob/master/lunar.js)。未引入其曆法或替換既有排盤引擎。

季節五行採寅卯木、巳午火、申酉金、亥子水、辰戌丑未土的月令分類；依當令、我生、生我、剋我、我剋排列旺、相、休、囚、死。此為所選季節分類，不是節氣司令分日算法，更不是日主強弱、格局或用神結論。

關係採用表集中於 `relationships()`：

- 天干：甲庚、乙辛、丙壬、丁癸沖；甲己、乙庚、丙辛、丁壬、戊癸五合。
- 地支：六合、六沖、六害、六破、子卯刑、辰午酉亥同支自刑；寅巳申與丑戌未兩支相刑另標刑組，三支齊備另標三刑。
- 三合與三會須三個不同地支齊備才列出，半合不當成完整組合。
- 午亥暗合僅採本次參考圖需要的這一項提示，標明藏干條件另判；不宣稱覆蓋全部暗合流派。
- 整柱列天沖地沖、天沖地刑。
- 每筆保留所有參與柱位，區分原局與運年引動。重複柱字仍保留不同柱位，單一午支不構成自刑。
- 五合、六合、三合、三會只列命中與組合條件，成局、成化、力量與喜忌另判；不自動把六合寫成某五行已化。

完整用神、格局與強弱的新版決策引擎不在本次匯出功能內；原頁面的簡化分析仍然存在，但不作為 Prompt 初判注入。
